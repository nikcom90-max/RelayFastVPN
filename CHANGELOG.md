# Что сделано

## Приложение (Android)
- Вкладка «Оплата»: тарифы из бота, оплата ЮKassa/Platega, статус платежа. Приложение само подписку не продлевает: дни начисляет бот после подтверждения платежа.
- Тарифы: под названием всегда «N устр. · M ГБ» (если админка не отдала лимиты, берутся из названия и описания); служебная приписка про TON скрыта.
- Скорость, трафик за сеанс и суммарный трафик на главном экране; то же в уведомлении и на экране блокировки; в уведомлении показан сервер.
- VPN поднимается сам после долгого сна экрана и перезагрузки (START_STICKY, переподключение при возвращении, подсказки про батарею и Always-on).
- Обновления из приложения: напрямую с GitHub Releases (репозиторий открытый, свои серверы не нужны), скачивание и установка внутри приложения.
- Камера QR: правила R8, чтобы CameraX/ML Kit не вырезались.

## Конфиг Xray / сеть
- Балансировщики и серверы берутся из Remnawave как есть, приложение их не перенастраивает.
- Для одиночных серверов домены не резолвятся на телефоне (AsIs); внутренний DNS Xray только IPv4, чтобы блок IPv6 не срабатывал на домены (причина «не грузит google.com»).
- Блокировка IPv6 из туннеля (QUIC блокируется на стороне сервера); sniffing без routeOnly (домен подставляется в соединение, обход подмены DNS провайдером).
- MTU туннеля 1500 (как у системного интерфейса); уровень политики tun берёт таймауты уровня 0.

## Windows
- Приложение для Windows: режимы системного прокси и TUN (wintun), установщик (.exe) и портативный ZIP, сборка в GitHub Actions.
- Те же правки, что на Android: конфиг Xray (домены на сервер, IPv4-DNS, IPv6-блок), вкладка оплаты и тарифы, скорость и трафик.
- Обновления: проверка на GitHub (теги windows-N), тихая установка и перезапуск.
- Один экземпляр: повторный запуск показывает уже открытое окно, а не открывает второе.

## Сборка
- Ядро Xray собирается на проверенной версии (авто-обновление до последней отключено из-за несовместимости с Go).
- Заглушка widget_test.dart удаляется при сборке; тесты обновлены.
- Подпись APK постоянным ключом через секреты KEY_ALIAS, KEYSTORE_PASS, KEYSTORE_B64.

## Сервер
- Платёжный прокси (proxy/app_proxy.py) скрывает секрет бота от приложения.
